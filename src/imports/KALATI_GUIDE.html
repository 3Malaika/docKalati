Aperçu du système

KALATI RAG est une application web full-stack qui permet aux agents CAMRAIL d'interroger en langage naturel une base documentaire interne (PDF, DOCX, TXT). Le système utilise la technique RAG (Retrieval-Augmented Generation) : il recherche les passages pertinents dans les documents puis génère une réponse précise via un LLM.

Frontend

Next.js 15 + React 19 + Tailwind CSS. Interface chat, dashboard admin, gestion vocale.

Backend

FastAPI (Python 3.11). API REST sécurisée JWT, pipeline RAG hybride, multimodalité PDF.

Données

ChromaDB (vecteurs), SQLite (audit + utilisateurs), fichiers JSON (manifeste d'accès).

Fonctionnalités principales

  • Recherche hybride : sémantique (vecteurs) + lexicale (BM25) fusionnées
  • Contrôle d'accès par groupe : chaque document est associé à un ou plusieurs groupes
  • Interface vocale : transcription Whisper → RAG → réponse audio (Piper TTS) — sur ordinateur, utiliser un casque avec microphone pour une transcription optimale
  • Multimodalité : tableaux et images des PDF extraits et indexés
  • Gestion des utilisateurs : CRUD complet depuis le dashboard admin
  • Journal d'audit : toutes les questions sont tracées dans SQLite

Utilisateur tape une question
↓
Frontend → POST /api/query
↓
Authentification JWT + vérification groupe
↓
Embeddings : Cohere API → vecteur requête
↓
Recherche hybride : ChromaDB (sémantique) + BM25 (lexical)
↓
LLM : Groq llama-3.3-70b → génère la réponse
↓
Réponse + sources retournées au frontend + audit SQLite

Modifier le code pour Ollama

Le fichier backend/app/infrastructure/llm_client.py doit être adapté :

# Remplacer l'import Groq par httpx/requests vers Ollama
import requests
from app.config import settings

class OllamaLLMGenerator:
    def generate(self, question: str, context_chunks: list) -> str:
        prompt = _build_prompt(question, context_chunks)
        response = requests.post(
            f"{settings.ollama_base_url}/api/generate",
            json={
                "model": settings.llm_model,
                "prompt": prompt,
                "stream": False,
            },
            timeout=120,
        )
        response.raise_for_status()
        return response.json()["response"].strip()

ollama_generator = OllamaLLMGenerator()

Le fichier backend/app/infrastructure/embeddings.py pour les embeddings Ollama :

import requests
from app.config import settings

def embed_texts(texts):
    embeddings = []
    for text in texts:
        r = requests.post(
            f"{settings.ollama_base_url}/api/embeddings",
            json={"model": settings.embedding_model, "prompt": text},
            timeout=60,
        )
        r.raise_for_status()
        embeddings.append(r.json()["embedding"])
    return embeddings

def embed_query(query):
    return embed_texts([query])[0]
